## What's Changed

### Internal cleanup: typed snapshots and strict typing (#50)

- **Always a snapshot:** the integration starts from an empty panel snapshot, so platforms
  never see "no data" (`None`) before the first refresh.
- **Zones with no reported state:** a zone whose open/closed state the panel hasn't reported
  shows *unknown* with the default icon, never an open-zone icon.
- **Typed data access:** platforms read the library's typed fields directly. Unused snapshot
  helpers were removed. After command timeouts, the hub still probes the link via
  `request_link_check` when the client provides it (getattr fallback for older elke27).
- **Strict mypy** runs in CI for the integration. Full strict typing waits for an elke27
  release that ships `py.typed`.

### Breaking changes

No breaking changes compared with 0.1.8 were found in #50 at 416257f:

- **The legacy stored `pin` is still removed on setup**, same as 0.1.8. #50 restored that
  cleanup.
- **The old `<base>_<domain>_<id>` unique-ID migration** was already gone in 0.1.8. The
  0.1.8 delete-and-re-add upgrade replaces those entities.

What to do: nothing extra if you're on 0.1.8. If you're upgrading **from 0.1.7 straight to
0.1.9**, follow the 0.1.8 **Before you upgrade** steps (delete the entry, upgrade, add it
again, then update entity references).
