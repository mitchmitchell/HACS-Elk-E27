## Upgrade

Update in HACS and restart Home Assistant. No re-link, no delete and re-add. Entity IDs,
registry IDs, areas, automations, dashboards and history are kept. Minimum Home Assistant
is unchanged (2026.10.0).

This release installs [`elke27` 0.5.1](https://pypi.org/project/elke27/0.5.1/) automatically
(was 0.5.0).

## What's new

- Panel command and service failures now show translated messages from `strings.json`
  (for example arm, disarm, bypass, lights, locks and garage doors).

## What changed

- Install instructions, the HACS button, the FAQ and release links now point at the official
  [ElkProducts/HACS-Elk-E27](https://github.com/ElkProducts/HACS-Elk-E27) repository. Issues
  stay on the development repository.

## Fixes

- Thermostat climate entities use Home Assistant's native temperature attributes
  (`native_temperature_unit`, `native_current_temperature`, and native setpoints) so import is
  clean on Home Assistant 2026.11 and later. A Home Assistant 2026.10 compatibility shim
  remains until minimum and test pins move to 2026.11.
- Diagnostics no longer call `importlib.metadata` on the Home Assistant event loop when
  reporting the installed `elke27` version.
